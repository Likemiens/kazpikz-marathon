# Менеджеру на площадке · Android

**Шаблон инструкции.** До передачи заменить названия экранов/кнопок и добавить
фото реальной панели. Эта версия описывает планируемое приложение; APK ещё не
поставлен. Окончательную инструкцию менеджер должен пройти на тесте сам.

## До Expo

Получить установленный APK, PIN оператора, проверенную флешку и контакт ответственного.
Вместе с поставщиком проверить питание, экран, способ запуска, отсутствие сна и
сохранение файла на флешку. Запомнить: fullscreen может отличаться от kiosk режима.
Не менять блокировки самостоятельно. Связь для удалённой установки нужна заранее.

## Начало дня

Запустить приложение штатным способом. Оно должно открыть выбор языка без загрузки
из интернета. Сверить дату/время в служебной информации, состояние базы, свободное
место, время последней копии. При красной ошибке сбора позвать ответственного,
не пытаться «очистить приложение». Убедиться, что начинается чистая посетительская
форма, не служебное окно с экспортом. Тестовые данные — только в отдельном демо.

## Выгрузить сообщения на флешку

Подключить проверенную флешку. Войти в служебный режим назначенным способом и PIN.
Нажать «Выгрузить сообщения». Приложение подготовит архив, затем откроет системное
окно Android «Сохранить». Выбрать **флешку**, а не облако, и сохранить новый ZIP.
Дождаться именно сообщения **«Выгрузка сохранена и проверена»**, не только закрытия
диалога. Вернуться к сбору. Извлечь флешку штатно по инструкции поставщика.

Открыть архив на компьютере: all.xlsx, 10km.xlsx, 21km.xlsx, 42km.xlsx,
moderation.xlsx, export-manifest.json. Убедиться, что файлы открываются и число
сообщений соответствует экрану выгрузки. Не переименовывать файлы внутри до
передачи ответственному. Пустая дистанция может содержать только заголовки.

Если выбрана «Отмена», запись прервалась, флешка исчезла или приложение сообщило
«Не удалось проверить», это **не готовая выгрузка**. Рабочая база остаётся в
приложении. Проверить носитель/место и повторить сохранение в новый файл; предыдущий
непроверенный архив не передавать для монтажа. Не удалять чужие файлы с флешки.

## Резервная копия — отдельное действие

Нажать «Сохранить резервную копию», выбрать флешку и дождаться проверки. Этот архив
содержит базу SQLite, не только Excel. Предлагаемый регламент: каждый час и после
окончания дня. Само наличие Excel не заменяет резервную копию. Локальная копия
на панели не поможет при её физической поломке или удалении приложения.

## Кто получает файлы

Весь экспортный ZIP и SQLite backup — только назначенному ответственному: внутри
есть телефоны. Модератору — moderation.xlsx без телефонов. Он ставит статусы и
создаёт отдельные файлы одобренных по дистанциям для монтажёра. Не выкладывать
контактную базу в общий чат и не отправлять на публичные сервисы проверки файлов.

## Между днями и финал

В конце первого дня сделать выгрузку/backup, закрыть штатно. Во второй день
продолжить ту же рабочую базу; не удалять первый день. Экспорт накопительный.
После закрытия 26.09 остановить сбор и сделать финальные ZIP/backup. Новая сырая
выгрузка не заменяет вручную размеченный Excel-мастер — его сохраняют отдельно.

## При сбое

Приложение закрылось: открыть штатно, убедиться, что база открылась и счётчик
сохранился. Сеть включать для работы сборщика не нужно. Ошибка базы: остановить
сбор, записать код/время, сообщить ответственному. Не фотографировать телефоны.
Флешка не видна: другой проверенный носитель/поставщик, только согласованный
fallback; нельзя считать файлы в памяти панели уже переданными на USB.

**Нельзя:** удалять приложение, нажимать Android «Очистить данные», сбрасывать
панель, переустанавливать APK с удалением старого, форматировать флешку с базой,
перезаписывать мастер модерации, заменять БД старой копией самостоятельно.
При конфликте обновления ключа/версии — остановиться, не uninstall.
