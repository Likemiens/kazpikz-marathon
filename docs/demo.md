# UX-демо

Демо в `demo/` предназначено для согласования гостевого сценария и визуальной адаптации на синтетических данных. Оно работает полностью локально в браузере, не делает сетевых запросов и не сохраняет содержимое формы.

## Что можно проверить

1. На стартовом экране выбрать `Қазақша`, `Русский` или `English`.
2. Выбрать 10, 21 или 42 км — переход происходит сразу, без лишней кнопки «Далее».
3. Отправить пустую форму и проверить ошибки у обязательных полей.
4. Ввести вымышленные имя, телефон формата `+77001234567` и пожелание.
5. Проверить экранную клавиатуру, переключение KK / RU / EN, caret/backspace и казахские Ә Ғ Қ Ң Ө Ұ Ү Һ І.
6. Нажать одну из двух быстрых фраз или открыть «Все фразы» и выбрать из восьми вариантов. Если пожелание уже заполнено, демо запросит подтверждение замены.
7. Отправить форму: сначала показывается состояние сохранения, затем горизонтальный экран с именем, пожеланием и дистанцией текущего посетителя.
8. Нажать «На главный экран» или дождаться автоматического возврата через 8 секунд — следующий посетитель увидит чистую сессию.

## Команды

```bash
cd demo
npm install
npm run dev
```

Проверка сборки:

```bash
npm run check
```

## Ограничения

- `submitDemoMessage` имитирует подтверждённый commit только в памяти текущей вкладки.
- Нет Capacitor, Kotlin bridge, SQLite, PIN, XLSX/ZIP, SAF, USB и Android lifecycle.
- Демо не является формой для сбора реальных контактов.
- Тексты, переводы, privacy-механизм и визуальная адаптация остаются предметом утверждения организатором.
- Основной reference viewport — landscape 1920×1080; фактическую геометрию нужно перепроверить на панели.

## Принцип безопасности

В демо нет localStorage, IndexedDB, аналитики и логирования пользовательских полей. После подтверждения форма очищается; перезагрузка также начинает новую сессию.
