# UX-потоки и состояния

Базовый путь подтверждён источниками. Таймеры, лимиты, размеры и детали клавиатуры — предложенные рабочие значения из PRD.

## Карта состояний

```text
BOOT → LANGUAGE → DISTANCE → FORM → SAVING → SUCCESS → LANGUAGE
                  ↑         ↓        ↓
             назад/смена   CANCEL   RETRY_SAME_ID

BOOT / любой storage failure → OUT_OF_SERVICE → действия менеджера
FORM + 90s idle → IDLE_WARNING + 15s → LANGUAGE
любой публичный экран → PIN → OPERATOR → LANGUAGE
```

`SAVING` не сбрасывается idle timer. При входе в технический режим с незавершённым сохранением сначала получить определённый результат; не терять in-flight request. Не менять язык, дистанцию и payload во время отправки.

## S01 · Выбор языка

Первый экран, не добавлять отдельную кнопку «Начать», которая удлиняет путь. Локальный KV / лого и три подписи на собственных языках: Қазақша, Русский, English. До получения KV использовать явный нейтральный development placeholder, не выдавать его за бренд.

После выбора устанавливается язык интерфейса и исходная раскладка. Порядок кнопок из брифа: kk / ru / en. Никакого сохранения предпочтений предыдущего гостя.

## S02 · Выбор дистанции

Три крупные кнопки 10, 21, 42 км. Подпись указывает, что это дистанция бегуна. Выбор сразу ведёт к форме; кнопка «Далее» не нужна. Назад — к языку.

## S03 · Компактная форма

Всегда видны выбранная дистанция, три подписи полей и понятная кнопка отправки. Имя и фамилия бегуна — одно поле. Пожелание — несколько строк с индикатором лимита. Телефон — текстовое поле с цифровой раскладкой.

В расширении две фразы располагаются около пожелания, не занимают отдельную страницу. Нажатие вставляет текст; когда поле не пусто, запрос «Заменить написанное?» защищает авторский ввод. Редактирование вставленной фразы обычное. Сохранение ID фразы не означает, что текст остался неизменным.

Ошибка обязательного поля видна у него и в коротком общем сообщении; фокус / визуальный акцент переходят к первой ошибке. Native Kotlin повторно проверяет правила по тому же набору тестовых векторов.

Назад к дистанции сохраняет текущий черновик внутри этой сессии. Кнопка «Начать заново» просит подтверждение при заполненных полях, затем очищает всё. Смена всего языка при заполненной форме также выполняется через новый старт, а не переводит введённый текст.

Юридический механизм — не утверждён: заложено место для локального уведомления и, при необходимости решения организатора, подтверждения. Не ставить галочку за пользователя. Не дописывать рекламные согласия самостоятельно.

## Экранная клавиатура

Активное поле определяет клавиатуру. Клавиши работают с текущим selection / caret, а не всегда дописывают в конец. Backspace удаляет видимый символ / выделение, не половину surrogate pair. Shift, пробел, дефис, апостроф и базовая пунктуация доступны.

На казахской раскладке должны быть Ә Ғ Қ Ң Ө Ұ Ү Һ І; в русском Ё не прятать за недоступным системным жестом. При наборе телефона доступны цифры и плюс, текст сохраняется строкой.

Предложенная кнопка переключения раскладки меняет только клавиатуру: выбранный язык интерфейса и metadata остаются прежними. Нельзя незаметно переводить введённое имя.

Отключить autocomplete и непрошеную системную клавиатуру в согласованной конфигурации; при этом физическая клавиатура полезна для тестов и не должна ломать state. Не применять `readonly` так, чтобы заблокировать все альтернативные способы ввода.

## S04 · Успех

Короткое «Пожелание отправлено!» и «Спасибо за поддержку!». Телефон и имя не повторять. Без конфетти, рейтинга, анимационной игры и обещания обязательного показа. Через 4 секунды или кнопку — новый старт. Введённые данные в UI очищаются сразу после подтверждённой записи.

## Ошибки и пустые состояния

- Невалидная форма: подсказки, данные остаются.
- Неопределённый результат записи: «Не удалось подтвердить сохранение» и повтор с прежним ID.
- Подтверждённый отказ записи: «Пожелание не сохранено», помощь менеджера; исходные данные в памяти до явной отмены / безопасного таймаута.
- БД повреждена / недоступна: экран обслуживания; не принимать новые обещания.
- Нет сообщений: техническое меню показывает ноль, выгрузка создаёт только заголовки.
- USB отменён / отключён: действие не выполнено, рабочая БД сохранна.
- Неверный PIN: отказ и ограничение попыток без раскрытия базы.

## Таймаут

Только реальная активность ввода / касания сбрасывает таймер. После 90 секунд — предупреждение с кнопкой «Продолжить». Ещё 15 секунд — очистка и старт. Медленная печать не должна сбрасываться из-за абсолютной длительности сессии. Значения настраиваются после проверки.

## Техническое меню

Скрытая точка входа — предложенное удержание отдельной служебной области 5 секунд; далее обязательный PIN. Нет видимого посетителю списка сообщений. Показывает здоровье хранения, количество по дистанциям, версию, время и последнюю подтверждённую внешнюю выгрузку.

Действия: «Выгрузить сообщения», «Сделать резервную копию», «Вернуться к сбору». Чужие формы не отображаются. При выходе / автоблокировке — очищенный старт. Нет кнопки «Удалить базу».
