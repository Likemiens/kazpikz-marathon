# UI: четыре экрана и рабочая клавиатура

Визуальный источник получен; [brand-spec](brand-spec.md) первичен. Локальный
[HTML-референс](../design/preview.html) и CSS-токены задают направление. Референс
не сохраняет данные, не проверяет права и не заменяет функциональную реализацию.

## Общая геометрия

Рабочий reference canvas 1920×1080 landscape — **Owner direction 14.09.2026**, заменяющее portrait-направление от 11.09.2026, до паспорта панели.
Физические 55″ ничего не говорят о CSS viewport/density. Реализация responsive,
но в договорном scope одна подтверждённая ориентация. Не растягивать root через
transform:scale; пересчитать layout под фактический viewport. Android rotation/
system bars/keyboard не должны скрывать активное поле или CTA.

Горизонтальный макет не считается физически подтверждённым до проверки монтажа.
Пропорции 16:9 сохраняются без механического растягивания KV.

Основной шрифт публичного интерфейса — **Roboto**, локально включённый в сборку:
400 для основного текста, 500 для вторичных акцентов, 700 для контролов и 900
italic для крупных спортивных заголовков/цифр. Это выбранный UI-шрифт, а не
утверждение об официальной гарнитуре бренда. Сетевые загрузки шрифтов запрещены.

Публичные контролы минимум 64 CSS px, промежутки 12; при 1920×1080 reference большие
кнопки 80–112. Форма читабельна с обычной дистанции использования. Основные
действия в зоне досягаемости; статичный логотип сверху не делает верхние края
экрана хорошим местом для частых касаний. Проверить человеком стоя/сидя.

## S01 · Язык / welcome

Верхняя кампейн-зона использует `kv-landscape-wide-v1.png` — отдельную
широкоформатную адаптацию исходного `kv-original.png`, подготовленную под
фактический слот ≈2.15:1. Она сохраняет два логотипа, слоган, бегунов и фактуру
трека, заполняя ширину без боковых полей и заметного кадрирования. В нижней
читаемой action-панели расположен крупный CTA: «Оставь пожелание
участнику марафона, и 27 сентября оно появится на городских экранах», затем выбор
«Қазақша», «Русский», «English». Нет кнопки «Начать» перед выбором языка. Порядок —
kk / ru / en, без флагов стран. Не дублировать логотипы или слоган поверх KV.

Кнопка языка сразу открывает дистанцию. Оригинальный широкий KV хранится отдельно
без изменений. Технические пометки и интернет-индикация на публичный экран не выводятся.

## S02 · Дистанция

Светлый app-header сохраняет оба официальных логотипа из верхней части исходного KV.
Заголовок «Какую дистанцию бежит участник?» в выбранной локали. Три крупные
равноправные белые поверхности 10 / 21 / 42 км на нейтральном фоне с чёткой
серой обводкой и без тени; красный
используется для числа и pressed-состояния, а не как заливка всего рабочего экрана.
Касание всей зоны выбирает дистанцию и ведёт в форму; нет лишнего «Далее».
Назад — язык. 10/21/42 не превращать в дополнительные названия категорий.

## S03 · Одна форма

Заголовок формы включает выбранную дистанцию: «Сообщение бегуну · 21 км» (с
локализованным эквивалентом). Отдельной плашки дистанции нет. Одна белая
поверхность содержит все три поля и CTA без вложенных карточек:
имя/фамилия бегуна и телефон отправителя сгруппированы в верхнем ряду, пожелание —
ниже на всю ширину. Ясно
различать чей телефон и чьё имя. В header видна выбранная дистанция и действие
«Изменить» без очистки уже введённых полей. Назад к языку с заполненной формой —
предупреждение о сбросе, не молчаливая потеря.

Шесть быстрых фраз расположены сеткой на всю ширину под пожеланием. «Все фразы»
открывает app-like overlay с полным набором из восьми;
это не новый экран сценария. Текст фразы вставляется в редактируемое поле; новое нажатие при изменённом тексте
подтверждается, чтобы не стереть собственные слова случайно. Отправка отдельно,
не по нажатию фразы. Счётчик символов и ошибки у поля. Утверждённое уведомление
о данных доступно локально, но не занимает постоянное место в форме до утверждения;
никаких обязательных маркетинговых чекбоксов без решения организатора.

Снизу постоянная область **собственной** клавиатуры во всю ширину canvas; она
компактна по высоте, начинается сразу с клавиш и не содержит пустой верхней зоны.
Активное поле понятно по выраженному focus-состоянию; название поля и подписи
раскладки `RU` / `123` над клавишами не дублируются.
Для имени/пожелания — выбранная kk/ru/en раскладка, для телефона цифровая с +,
backspace и переходом к следующему полю. Разрешить переключить раскладку текста
без смены интерфейсного языка. Реализовать caret/selection, deletion по графемам,
shift, space, punctuation и мягкий перенос; Android системная IME не должна
вылезать одновременно. Один только inputmode=none не считать доказательством
подавления IME: проверить WebView/OEM и доступный native способ. Не использовать
readonly input как замену полноценному редактированию без проверки accessibility.

CTA «Отправить пожелание» остаётся видимым вместе с активным полем. В saving
поля/фразы заблокированы, визуально показана запись. Повторный tap не новый ID.
Валидация без отправки переводит фокус к ошибке. Сбой native-storage не ведёт в S04.

## S04 · Подтверждение

S04 — телевизионная 16:9 композиция для городских экранов. Весь canvas залит
фирменным красным, включая верхнюю логотипную зону: отдельной текстурной KV-плашки
нет. Официальный белый Kaspi.kz и точный Almaty Marathon размещены самостоятельными
lockup-элементами прямо на общем фоне. В центре без карточки и служебных элементов крупно показываются подпись
«Пожелание для», имя бегуна, само пожелание и дистанция. Телефон, checkmark,
статусная колонка и кнопка возврата не выводятся. Длинные имя и пожелание
уменьшаются по заданным length-классам, сохраняя читаемую иерархию.

В обычном сценарии S04 виден 8 секунд, затем открывается чистый S01. Такой
публичный показ production-данных требует отдельного согласования.

Для презентации S04 доступен напрямую по `?screen=final`; `lang=kk|ru|en`
переключает локаль синтетического примера. Прямой просмотр не запускает
восьмисекундный reset и остаётся на экране до смены URL. Эта ссылка не является
операторским режимом и не должна показывать реальные записи.

## Служебные состояния

Idle: после 90 сек без активности локальное предупреждение 15 сек, затем очистка.
Не reset во время PENDING commit, unresolved retry, export или системного picker.
Resume app: не всплывает чужая форма, operator session закрыта по контракту.
Storage error: закрыть сбор, ясное сообщение «Позовите менеджера» и безопасный код;
не изображать ошибку интернета. USB error/cancel только в служебном режиме.

Оператор входит через отдельную небрендовую скрытую область/жест + PIN; не делать
нажатие на логотип обязательной секретной кнопкой. PIN, диагностика, экспорт,
backup и вернуться к сбору — всё. Никакой таблицы всех телефонов на киоске.

## Компоненты и визуальное поведение

Компонентный язык следует актуальному Super App: нейтральный фон, белые поверхности,
мягкий радиус, тонкие разделители и минимум тени. #F14635 резервируется для CTA,
выбора и фокуса. Функциональные заголовки — Roboto 700/900; заголовок формы
получает 900 italic как прямое продолжение наклонной KV-типографики, но сохраняет
обычный регистр и не превращается в капс.

Все публичные тексты используют обращение на «ты». Приписка «Его могут включить
в ролик поддержки» не используется. Инструкции не набираются мелким кеглем:
если пояснение не помещается как читаемый основной текст, его нужно убрать или
перенести в служебную документацию.

Кнопка default/pressed/focus/disabled/loading; поле empty/focused/filled/error;
фраза default/selected/edited; storage status ready/saving/blocked. Ошибки текстом,
не только цветом. Без масштабирования логотипа как press effect. Motion максимум
простое fade 120–180 мс, reduced-motion поддержать; анимация не обязательна.
В keyboard использовать настоящие button/label/focus semantics, а не холст.

## Ограничения reference

HTML показывает доступные материалы и предложенную композицию, с синтетическими
полями и ручным выбором экранов/языков. Не реализует timer, сохранение, настоящую
клавиатуру, копии и операторское меню. Его отсутствие ввода — намеренная защита
от использования как настоящего сборщика. В production эти детали реализуются
по PRD, не копируются из demo-переключателя.
