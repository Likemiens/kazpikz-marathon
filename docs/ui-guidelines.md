# UI: четыре экрана и рабочая клавиатура

Визуальный источник получен; [brand-spec](brand-spec.md) первичен. Локальный
[HTML-референс](../design/preview.html) и CSS-токены задают направление. Референс
не сохраняет данные, не проверяет права и не заменяет функциональную реализацию.

## Общая геометрия

Рабочий reference canvas 1920×1080 landscape — **Assumed** до паспорта панели.
Физические 55″ ничего не говорят о CSS viewport/density. Реализация responsive,
но в договорном scope одна подтверждённая ориентация. Не растягивать root через
transform:scale; пересчитать layout под фактический viewport. Android rotation/
system bars/keyboard не должны скрывать активное поле или CTA.

До подтверждения монтажа не считать landscape финальным решением. Если панель
установлена вертикально, подготовить отдельную 9:16-композицию вместо letterbox
или механического складывания текущего широкого макета.

Основной шрифт публичного интерфейса — **Roboto**, локально включённый в сборку:
400 для основного текста, 500 для вторичных акцентов, 700 для контролов и 900
italic для крупных спортивных заголовков/цифр. Это выбранный UI-шрифт, а не
утверждение об официальной гарнитуре бренда. Сетевые загрузки шрифтов запрещены.

Публичные контролы минимум 64 CSS px, промежутки 12; при 1920 reference большие
кнопки 80–112. Форма читабельна с обычной дистанции использования. Основные
действия в зоне досягаемости; статичный логотип сверху не делает верхние края
экрана хорошим местом для частых касаний. Проверить человеком стоя/сидя.

## S01 · Язык / welcome

Широкая композиция: слева исходный KV целиком с обоими логотипами; справа
приглашение и три крупные кнопки «Қазақша», «Русский», «English». Нет кнопки
«Начать» перед выбором языка. Предлагаемый текст приглашения можно дать на
трёх языках компактно: локаль ещё не выбрана, старт не должен быть только русским.
Порядок языков из брифа — kk / ru / en. Не использовать флаги стран.

Кнопка языка сразу открывает дистанцию. KV сохраняет исходный текст без попытки
машинного перевода изображения. Технические пометки о статусе прототипа не
показывать на публичном экране. Никакой интернет-индикации «офлайн = ошибка».

## S02 · Дистанция

Сплошной тёмный header с оригинальным Kaspi и локализованным названием события.
Заголовок «На какой дистанции бежит ваш участник?» в выбранной локали. Три крупные
равноправные зоны 10 / 21 / 42 км; графика белых полос напоминает дорожку.
Касание всей зоны выбирает дистанцию и ведёт в форму; нет лишнего «Далее».
Назад — язык. 10/21/42 не превращать в дополнительные названия категорий.

## S03 · Одна форма

Одна светлая рабочая область: имя/фамилия бегуна и телефон отправителя сгруппированы;
большое поле пожелания рядом/ниже в зависимости от измеренной ширины. Ясно
различать чей телефон и чьё имя. В header видна выбранная дистанция и действие
«Изменить» без очистки уже введённых полей. Назад к языку с заполненной формой —
предупреждение о сбросе, не молчаливая потеря.

Две фразы — небольшие, но достаточно крупные для касания кнопки рядом с пожеланием.
Текст фразы вставляется в редактируемое поле; новое нажатие при изменённом тексте
подтверждается, чтобы не стереть собственные слова случайно. Отправка отдельно,
не по нажатию фразы. Счётчик символов и ошибки у поля. Утверждённое уведомление
о данных доступно локально, но не занимает постоянное место в форме до утверждения;
никаких обязательных маркетинговых чекбоксов без решения организатора.

Снизу постоянная область **собственной** клавиатуры; активное поле понятно по
выраженному focus-состоянию, его название над клавишами не дублируется.
Для имени/пожелания — выбранная kk/ru/en раскладка, для телефона цифровая с +,
backspace и переходом к следующему полю. Разрешить переключить раскладку текста
без смены интерфейсного языка. Реализовать caret/selection, deletion по графемам,
shift, space, punctuation и мягкий перенос; Android системная IME не должна
вылезать одновременно. Один только inputmode=none не считать доказательством
подавления IME: проверить WebView/OEM и доступный native способ. Не использовать
readonly input как замену полноценному редактированию без проверки accessibility.

CTA «Отправить пожелание» остаётся видимым вместе с активным полем. В saving
поля/фразы заблокированы, визуально показана запись. Повторный tap не новый ID.
Валидация без отправки переводит фокус к ошибке. Сбой native-storage не ведёт в S04.

## S04 · Подтверждение

Спокойная композиция на тёмном фоне с белой линией/маркером, не game/confetti.
«Пожелание сохранено!» / локализованный эквивалент. Допустимый смысл «Спасибо за
поддержку»: не обещать, что послание точно появится на LED. Через 4 секунды
(рабочая настройка) чистый S01; кнопка «Готово» позволяет вернуться раньше.
Не показывать телефон или всё содержимое предыдущей формы на благодарности.

## Служебные состояния

Idle: после 90 сек без активности локальное предупреждение 15 сек, затем очистка.
Не reset во время PENDING commit, unresolved retry, export или системного picker.
Resume app: не всплывает чужая форма, operator session закрыта по контракту.
Storage error: закрыть сбор, ясное сообщение «Позовите менеджера» и безопасный код;
не изображать ошибку интернета. USB error/cancel только в служебном режиме.

Оператор входит через отдельную небрендовую скрытую область/жест + PIN; не делать
нажатие на логотип обязательной секретной кнопкой. PIN, диагностика, экспорт,
backup и вернуться к сбору — всё. Никакой таблицы всех телефонов на киоске.

## Компоненты и визуальное поведение

Кнопка default/pressed/focus/disabled/loading; поле empty/focused/filled/error;
фраза default/selected/edited; storage status ready/saving/blocked. Ошибки текстом,
не только цветом. Без масштабирования логотипа как press effect. Motion максимум
простое fade 120–180 мс, reduced-motion поддержать; анимация не обязательна.
В keyboard использовать настоящие button/label/focus semantics, а не холст.

## Ограничения reference

HTML показывает доступные материалы и предложенную композицию, с синтетическими
полями и ручным выбором экранов/языков. Не реализует timer, сохранение, настоящую
клавиатуру, копии и операторское меню. Его отсутствие ввода — намеренная защита
от использования как настоящего сборщика. В production эти детали реализуются
по PRD, не копируются из demo-переключателя.
