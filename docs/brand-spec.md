# Брендинг · Kaspi.kz × Almaty Marathon

v2.0. Это спецификация применения переданных материалов, а не их редизайн.
**Received ≠ screen approved.** Источники и наблюдения отделены от предлагаемых
решений, чтобы Codex не превращал интерпретацию в «требование брендбука».

## 1. Что дано источниками

**SRC-04, KV PNG 1224×684.** Терракотовая беговая дорожка, белая горизонтальная
разметка, две фигуры бегунов, белые знаки Kaspi.kz слева и Almaty Marathon справа.
Наклонные тяжёлые белые строки: «10 ЖЫЛ», «ҚАРҚЫНДЫ», «ҰСТАП КЕЛЕМІЗ».
Это растр с уже сведёнными надписями/фото/логотипами, не набор отдельных слоёв.
Не приписывать ему буквенную гарнитуру, pantone, фактическую годовщину или новые
слоганы, которых источник не определяет. Слоган остаётся частью исходного KV;
текст приложения «Твои слова помогут добежать» — из концепции Саши.

**SRC-05, PDF правил Kaspi.kz.** Страница 2 задаёт RGB 241/70/53, HEX #F14635.
Страница 4 показывает основной горизонтальный логотип на светлом/красном/чёрном.
Страница 5: ч/б версия предназначена только для ч/б печати. Страница 6 описывает
упрощённый знак и печатный минимум 10 мм — не переносим миллиметры в CSS автоматически.
Страница 7 требует контраст. Страница 8: на дробном фоне нужна плашка со свободным
полем. Страница 9 запрещает поворот, искажения/перестановку, другой цвет, эффекты,
прозрачность, плохой контраст, посторонние элементы и нарушение охранного поля.
Численного соотношения охранного поля в просмотренных правилах не задано;
значения ниже — предложение UI, не норматив Kaspi.kz.

**SRC-06, ZIP.** Выбранные оригинальные SVG и PNG находятся в assets/brand/logos.
Пропорции и цвета сохранены. Есть варианты основного и упрощённого Kaspi.kz;
самостоятельного Almaty Marathon в этом архиве нет.

## 2. Предлагаемая визуальная логика

Пусть приложение продолжает тему дорожки, а не превращает KV в фон анкеты.
Welcome — полный исходный KV и отдельная читаемая зона выбора языка. Далее
сохраняем глубокий красно-коричневый фон, белые линии и крупные номера дистанций;
форма/клавиатура — светлые ровные поверхности. Не накладывать текст/поля на бегунов.
Не добавлять неон, glassmorphism, градиенты, конфетти, 3D и игровые эффекты.

Оригинал KV не кропить ради `cover`. Размер 1224×684 достаточен для умеренной
иллюстративной зоны; качество при растягивании на всю 4K панель не подтверждено.
В `contain` сохранить оба логотипа и все строки. Для иных кропов нужен исходник
без надписей/слои и согласование; не вырезать спортсменов автоматически.

## 3. Цвет

Официальный акцент **#F14635** — только из PDF, с.2. Не перекрашивать лого в
терракоту. Цвет дорожки #862C19 и тёмный #5E1E12 — медианы двух однородных зон
переданного PNG, не официальные оттенки. Координаты в design-tokens.json.

Белая поверхность, тёмный текст #241A17, вторичный #65544D, светлый фон #FFF9F5,
граница #AA8A7F и текст ошибки #A3261A — предлагаемые UI-значения. Ошибка не
обозначается одним красным: добавить текст/иконку. Белый мелкий текст на ярком
#F14635 не использовать как базовую пару; для белого CTA выбираем тёмную дорожку,
для красного акцента — тёмную надпись. Контраст проверяется скриптом для заданных
пар, не заменяет проверку реальной яркости/освещения панели.

## 4. Логотипы и совместное размещение

В welcome полный KV уже содержит оба бренда: не дублировать Kaspi ещё раз поверх
или рядом без необходимости. На функциональных экранах — оригинальный белый
горизонтальный Kaspi.kz на сплошном тёмном header. Название Almaty Marathon обычным
текстом обозначает событие; это **не воспроизведение отсутствующего знака**.
Если заказчику нужно оба самостоятельных логотипа на каждом экране, запросить
вектор Almaty Marathon, затем заменить текст. Не подменять его словом, нарисованным
похожим шрифтом, и не «восстанавливать» вектор по PNG.

Логотип img с width auto/height фиксированной, object-fit contain; без rotate,
skew, CSS filter, opacity, shadows и редактирования path. Свободное поле со всех
сторон — предложено минимум 0.5 высоты полного знака; не подписывать это правилом
Kaspi. У header достаточно ширины для него. Не использовать маленький symbol-only
там, где помещается полный логотип. Не добавлять QR/Red+ из PDF: их нет в scope.

## 5. Типографика

Из KV наблюдается тяжёлый наклонный grotesk, но точное название гарнитуры не дано.
Для публичного UI выбран Roboto: body 400/500, контролы 700, display 900 italic.
Шрифт включён локально в приложение и не требует сети. Не утверждать, что Roboto —
официальная гарнитура бренда: шрифтов в исходном ZIP нет, а фирменный текст KV уже
встроен в изображение и не требует webfont.

Для 1920×1080 рабочего CSS canvas: заголовки 64–84, крупные дистанции 100–140,
body 26–32, label 22–26, клавиша 26–32 CSS px. Это ориентиры, не масштабирование
55″ в пиксели. Проверить kk/ru/en и все Ә Ғ Қ Ң Ө Ұ Ү Һ І, длину переводов,
плотность Android, высоту размещения и досягаемость.

## 6. Передача в код

Начать с tokens.css; CSS-переменные семантические, не жёстко красить каждый div.
Логотипы и KV импортировать локально. Не загружать ассеты из CDN/Figma/интернета
при запуске. Подробная композиция и состояния — в ui-guidelines.md.
HTML-референс показывает одно направление, не три новых концепции.

## 7. Приёмка дизайна

Отдельно подтвердить адаптацию Сашей/организатором. Сверить отсутствие кропа KV,
искажения/прозрачности логотипов, мелкого текста на плохом контрасте, потери
казахских букв и двойной клавиатуры. Все публичные состояния + ошибки/idle +
служебный режим на фактическом Android. Пока productionVisualApproved=false.
