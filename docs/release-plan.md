План, не выполненные действия. Expo 25–26.09, показ 27.09; год 2026/Asia-Almaty
рабочие до подтверждения. Приложение готово до открытия Expo 25 сентября.

## Предлагаемые контрольные точки

11.09 — паспорт/доступ/USB и первый APK spike; 14.09 — branded экраны и локальные
ресурсы; 18.09 — контент/словарь/privacy; 21.09 — release candidate; 22–24.09 —

Саши/железа; первый аппаратный тест нельзя молча переносить на день Expo.

## Выход реализации

Signed release APK с версией и SHA-256, исходники+lockfile/toolchain, инструкция,
паспорт панели, результаты проверок, локальный PIN setup, USB/backup памятка.
Ключ подписи хранится у владельца безопасно, не в Git/в документационном ZIP.
Полный набор ассетов в APK, без Google Play/login/download на первом запуске.

## Gates перед реальными посетителями

GATE-TARGET: точный Android/WebView/ABI/display подтверждены, выбранные зависимости
и режим SQLite реально работают на панели. GATE-USB: SAF-write/read-back/Excel
и backup/restore выполнены, kiosk не мешает. GATE-DATA: утверждены обработка
контактов и сроки/доступ, Auto Backup/D2D не создают несанкционированные копии.
GATE-CONTENT: kk/ru/en/словарь/бренд-экраны утверждены человеком. GATE-QUALITY:
AC-01…19 закрыты доказательствами, нет blocker-defects. GATE-OPS: менеджер
самостоятельно запускает, выгружает, делает копию и передаёт назначенной команде.

Параметр productionAllowed остаётся false, пока все условия не приняты. Скрипт
пакета не открывает его. Офлайн-APK со placeholder privacy не production ready.

## Demo → production

Демо с отдельным applicationId/данными. Передавать чистый production APK, не
очищать реальную БД удалением программы. Зафиксировать device_id, версию, часы,
первую проверенную внешнюю копию; реальные телефоны не использовать для теста.

Установка APK через разрешённый источник заранее; обновление тем же ID/ключом
с большим versionCode, после backup. При конфликте подписи/версии остановиться,
не uninstall. Автообновления/смена схемы в Expo не планируются.

## Эксплуатация

Каждый день до открытия: питание, часы, cold start, три языка, успешный export
на тестовом контуре, место на диске/носителе. В рабочей базе не смешивать тесты.
Локальные копии примерно 5min между сессиями; внешние по предложенному регламенту
каждый час и после закрытия. При простое — backup как только безопасно доступен.

26.09 после закрытия: остановить приём → финальный ZIP + отдельный SQLite backup →
чтение на ноутбуке → контактные файлы ответственному → moderation модератору →
одобренные файлы контент-команде в согласованный час. Не весь ZIP в общий чат.
На следующий день приложение не управляет LED и не рендерит ролик.

## Инциденты

Storage error: pause, код/время/версия без PII, сохранить БД, не переписывать/удалять.
USB error/cancel: проверить носитель и повторить новый документ, старый непроверенный
не передавать. Коррупция: восстановление только разработчиком из согласованной
копии с сохранением текущего состояния. Менеджер не нажимает clear data/factory reset.

Физическая потеря устройства покрывается только сохранёнными внешними копиями;
не обещать сохранность записей после последней такой копии при гибели носителя.
Удалённое подключение без связи невозможно; инструкция — основной способ работы.
