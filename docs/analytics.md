# Измерение без внешней аналитики

Отдельная аналитическая платформа не нужна. Никаких SDK Яндекс.Метрики, Google Analytics, remote logging или записей пользовательского экрана.

## Локальные показатели

Менеджер видит число успешно сохранённых записей всего и по дистанциям, версию приложения, состояние БД и время последней успешной внешней выгрузки. Счётчики читаются из фактической БД, не увеличиваются оптимистично в UI до commit.

Технические события: запуск, завершение, ошибки хранения по коду, результат backup/export и число строк. Без телефона, имени, пожелания, PIN и содержимого формы. Количество успешных записей берётся из SQLite; не требуется параллельная сложная event database.

## Скорость

Время 20–30 секунд из брифа проверяется секундомером / тестовым сценарием на панели. Записать число участников, язык, свободный ввод или готовая фраза, длительность и проблему. В рабочем приложении не нужен дополнительный идентификатор посетителя, трекинг воронки и связь телефона с аналитикой.

## Отчёт после Expo

Число записей по дистанциям и языкам; сколько одобрено / отклонено / использовано по master-таблице; технические простои; наличие финального backup; получение трёх выборок контент-командой. Эти показатели относятся к разным источникам и не смешиваются в якобы live dashboard.
