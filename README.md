# kazpikz-marathon

Интерактив для touch-панели Kaspi.kz × Almaty Marathon: посетитель выбирает язык и дистанцию, оставляет пожелание бегуну и получает подтверждение после сохранения.

## Текущий статус

В репозитории готова интерактивная браузерная UX-демка полного гостевого пути:

- три языка: қазақша, русский и English;
- дистанции 10 / 21 / 42 км;
- форма с валидацией, готовыми фразами и собственной экранной клавиатурой;
- безопасная имитация сохранения, экран подтверждения и очистка сессии;
- адаптивная композиция на основе оригинального KV и логотипов из бренд-пака.

Демо не сохраняет введённые данные и предназначено только для синтетических тестов. Это не Android APK и не подтверждение готовности SQLite, USB-выгрузки, kiosk-режима или работы на реальной панели.

## Быстрый старт

```bash
cd demo
npm install
npm run dev
```

После запуска откройте `http://localhost:5173`.

Полная локальная проверка:

```bash
cd demo
npm run check
```

Команда выполняет TypeScript strict-check, production build и smoke-тест Sites-compatible worker.

## Структура

- `demo/` — рабочая React + TypeScript + Vite демка.
- `assets/brand/` — исходный KV, логотипы и UI-токены.
- `content/` — черновые локали, фразы и раскладки.
- `docs/` — PRD, UX, архитектура, тесты, риски и текущий статус.
- `design/` — исходный HTML-reference и контрольные скриншоты.
- `specs/` — будущие контракты Android native bridge, SQLite и экспорта.

Начать знакомство лучше с [демо](docs/demo.md), затем прочитать [статус проекта](docs/project-status.md), [PRD](docs/prd.md), [решения](docs/decisions.md), [UI-гайд](docs/ui-guidelines.md) и [архитектуру](docs/architecture.md).

## Граница демо и production

Production-направление из PRD — React/TypeScript/Vite в Capacitor-оболочке, Kotlin bridge, приватная SQLite и экспорт ZIP через Android Storage Access Framework. Следующий инженерный срез — T00: минимальный APK, synthetic insert → commit → restart → count → USB read-back на целевом устройстве.

До согласования privacy-текста, переводов и правил модерации нельзя использовать реальные имена и телефоны. Не помещайте персональные данные, PIN, ключи подписи, APK, базы или выгрузки в Git.
