# Оригиналы и правила применения

`kv-original.png` — весь переданный KV, 1224×684. Не ретуширован и остаётся
архивным источником. `kv-portrait-v3.png` — отдельная сгенерированная 9:16
адаптация по прямому запросу владельца от 11.09.2026: два бегуна и фактура трека,
без текста и логотипов. В интерфейсе поверх неё используется подлинный Kaspi SVG.
Портретная адаптация предложена для согласования и не подменяет оригинал.

`logos/kaspikz-logo-white.svg` — белый горизонтальный логотип для тёмной сплошной
подложки. `logo-1` — цветной знак и тёмное слово на светлой. `logo-2` — цветной знак
и светлое слово на тёмной. `logo-small-red` — упрощённый знак из исходного ZIP,
не предпочтительная замена полному лого для 55″. PNG-дубликаты — fallback.
Исходные логотипы перенесены без правок. Чёрно-белая печатная версия не нужна
текущему интерфейсу, поэтому не добавлена в runtime-кандидаты.

PDF всех правил: [sources/kaspi-logo-guidelines.pdf](../../sources/kaspi-logo-guidelines.pdf).
Он содержит также QR и Red+, но эти продукты не участвуют в приложении.
`design-tokens.json`/`tokens.css` — предложенная UI-адаптация, не новый брендбук.
Подробности, источники и ограничения: [brand-spec](../../docs/brand-spec.md).

Самостоятельный логотип марафона отсутствует; его не восстанавливать из пикселей
как «официальный SVG». Гарнитура исходного KV не идентифицирована и не вынесена
из изображения; для интерфейса приложение отдельно и локально включает Roboto.
