# Локальный визуальный референс

Открыть preview.html в браузере, без сервера и сети. Переключатель сверху — служебный,
не часть продукта. Рабочий макет 1920×1080 landscape — предположение; интерфейс
масштабируется по композиции, но две ориентации не обещаны заказчику.

4 состояния, 3 языка, реальные KV/SVG и предложенные UI-токены. Поля только
синтетический текст, клавиатура только демонстрация геометрии. Сохранения, таймеров,
настоящего ввода, SQLite и Android интеграции нет. Статус «не приложение» всегда виден.

Казахские/английские тексты — прежние draft-локали пакета. Самостоятельный знак
марафона и фирменный шрифт не поставлены. Полный KV на старте сохраняет оба бренда.
На остальных экранах название мероприятия набрано обычным текстом, не «новое лого».

Экранная композиция proposed; visual approval и Android panel QA отдельно.

## Проверка этого reference

Выполнен desktop Chromium render 4 экранов × 3 локалей при 1920×1080.
Исходные HTML/CSS/JS/ассеты для рендера подставлены в память: навигация по file://
и loopback HTTP в среде проверки заблокирована политикой браузера. Поэтому
прямое открытие локального файла именно в этой среде не проверено. Сам reference
не содержит сетевых зависимостей. Результаты в preview-checks.json, изображения
в screenshots/. Эта проверка не закрывает ни APK, ни Android WebView, ни тач-панель.
